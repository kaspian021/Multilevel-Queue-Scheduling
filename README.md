# تمرین ۸ - مسئله فیلسوفان غذاخور

این شاخه پاسخ مفصل تمرین ۸ را در **گزارش فارسی ۳۸ صفحه‌ای** ارائه می‌کند.

## پاسخ محوری
الگوریتم اصلی MLQ مخزن، سه صف با اولویت ثابت دارد و فرمان‌ها را ترتیبی اجرا می‌کند. در کد اصلی، تخصیص چنگال/قفل و هماهنگی نخ‌ها پیاده‌سازی نشده است؛ بنابراین نسخه موجود به‌تنهایی نه بن‌بست و نه گرسنگی فیلسوفان را تضمیناً حل می‌کند. منطق صف‌بندی قابل استفاده مجدد است، اما باید با ترتیب سراسری اخذ منابع و صف FIFO منصفانه تکمیل شود.

## اجرای محلی
```bash
python -m pip install -r requirements.txt
python code/model_check.py
python code/dining_philosophers.py --philosophers 5 --meals 3
python -m pytest -q tests
python code/make_diagrams.py
python build_report.py
```

مدل محدود برای پنج فیلسوف، روش «اول چپ، سپس راست» را با یک وضعیت بن‌بست و روش پیشنهادی `N-1 + global resource order` را بدون وضعیت بن‌بست گزارش می‌کند. آزمون‌ها باید در محیط محلی با `8 passed` پایان یابند.

**دامنه ادعا:** نبود بن‌بست در فضای حالت مدل‌شده گزارش می‌شود؛ استدلال عدم گرسنگی علاوه بر FIFO به پایان متناهی غذاخوردن و عدالت زمان‌بند نخ‌ها وابسته است.
