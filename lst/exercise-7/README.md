## پرسش

وقتی چند کار لَکسیَتیِ برابر دارند — که در لَکسیَتیِ صفر زیاد پیش می‌آید — چه باید کرد؟ و آیا هزینه‌ی پیش‌گیری‌های پیاپی LST را از یک الگوریتمِ خوب به یک الگوریتمِ روی‌کاغذ تنزل می‌دهد؟

## روش

پنج سیاستِ تساوی‌شکنی به عنوان یک پارامترِ صریح (نه یک جزئیاتِ پیاده‌سازی)، اندازه‌گیریِ هزینه‌ی پیش‌گیری روی هزاران مجموعه‌کار، و جستجوی جامع برای اینکه بفهمیم تساوی‌شکنی بهینگی را عوض می‌کند یا نه. مقایسه با EDF و با دورگه‌ی EDF-LST.

## معیارها

پیش‌گیری، تعویضِ زمینه، تعویض در لَکسیَتیِ صفر، نرخِ خطا، و حکمِ بهینگی برای هر سیاست.

## تحویل‌داده‌ها

گزارشِ دوزبانه (EN/FA)، DOCX + PDF، ۲۰ تا ۴۰ صفحه برای هر فایل

## چطور اجرایش کنیم

```bash
python3 code/run_experiments.py     # عددها -> output/experiments.json
python3 code/make_diagrams.py       # شکل‌ها -> diagrams/

```

ساختِ گزارش از ریشه‌ی درختِ چندتمرینیه (جایی که پوشه‌های exercise-N کنارِ
هم‌اند):

```bash
python3 tools/build_report.py lst7_en exercise-7 REPORT_EN
python3 tools/build_report.py lst7_fa exercise-7 REPORT_FA
```
