## پرسش

لَکسیَتی (slack) چیست، LST دقیقاً چه چیزی را کمینه می‌کند، و چرا این انتخاب معنا دارد — نه فقط «یک الگوریتمِ اولویتِ پویای دیگر».

## روش

تعریفِ صوریِ لَکسیَتی، شبه‌کد، یک مثالِ گام‌به‌گام که با دست حل می‌شود، و یک شبیه‌ساز با زمانِ صحیح (بدون اعشار) که همان مثال را بازتولید می‌کند. هر ادعای عملکردی با اندازه‌گیری است، هر ادعای درستی با بررسی.

## معیارها

تعدادِ پیش‌گیری‌ها، تعدادِ تعویضِ زمینه، کمینه‌ی لَکسیَتیِ مشاهده‌شده، نرخِ از دست دادنِ ضرب‌الاجل.

## تحویل‌داده‌ها

گزارشِ دوزبانه (EN/FA)، DOCX + PDF، ۲۰ تا ۴۰ صفحه برای هر فایل

## چطور اجرایش کنیم

```bash
python3 code/run_experiments.py     # عددها -> output/experiments.json
python3 code/make_diagrams.py       # شکل‌ها -> diagrams/
python3 -m pytest tests -q          # تست‌ها
```

ساختِ گزارش از ریشه‌ی درختِ چندتمرینیه (جایی که پوشه‌های exercise-N کنارِ
هم‌اند):

```bash
python3 tools/build_report.py lst1_en exercise-1 REPORT_EN
python3 tools/build_report.py lst1_fa exercise-1 REPORT_FA
```

باز کردنِ شاخه دیده شود.
