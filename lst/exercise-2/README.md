## پرسش

در بارهای کاریِ مختلف، LST در برابر EDF و RM کجا می‌برد و کجا می‌بازد — و آیا اصلاً معیارِ «بردن» یکی است؟

## روش

شبیه‌سازیِ رخداد-گسسته با زمانِ صحیح روی چند سناریوی بارِ کاری (عادی، فشار، بیش‌بار، دوره‌های هم‌ساز و ناهم‌ساز). هر سناریو در یک فایل است و برای ورودیِ یکسان خروجیِ یکسان می‌دهد.

## معیارها

نرخِ از دست دادنِ ضرب‌الاجل، پیش‌گیری، تعویضِ زمینه، زمانِ پاسخ و لرزشِ آن، رفتارِ زیرِ بیش‌بار.

## تحویل‌داده‌ها

گزارشِ دوزبانه (EN/FA)، DOCX + PDF، ۲۰ تا ۴۰ صفحه برای هر فایل

## چطور اجرایش کنیم

```bash
python3 code/run_experiments.py     # عددها -> output/experiments.json
python3 code/make_diagrams.py       # شکل‌ها -> diagrams/
python3 -m pytest tests -q          # تست‌ها
```

ساختِ گزارش از ریشه‌ی درختِ چندتمرینیه (جایی که پوشه‌های exercise-N کنارِ
هم‌اند):

```bash
python3 tools/build_report.py lst2_en exercise-2 REPORT_EN
python3 tools/build_report.py lst2_fa exercise-2 REPORT_FA
```
