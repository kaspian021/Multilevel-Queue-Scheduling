## پرسش

یک مجموعه‌کارِ کوچک که با دست و گام‌به‌گام زمان‌بندی شود، درست به شکلی که استاد انتظار دارد.

## روش

جدولِ زمان‌بندیِ دستی (چه کاری در هر واحدِ زمان، لَکسیَتیِ هر کاری در هر تصمیم)، به همراه اسکریپتی که همان جدول را با همان اعداد چاپ می‌کند. زمانِ صحیح است، پس جوابِ دستی و خروجیِ برنامه باید ذره‌به‌ذره یکی باشند — و تست همین را چک می‌کند.

## معیارها

تطابقِ کاملِ جدولِ دستی با خروجیِ برنامه؛ نمودارِ گانتِ هردو.

## تحویل‌داده‌ها

گزارشِ دوزبانه (EN/FA)، DOCX + PDF، ۲۰ تا ۴۰ صفحه برای هر فایل

## چطور اجرایش کنیم

```bash
python3 code/run_experiments.py     # عددها -> output/experiments.json
python3 code/make_diagrams.py       # شکل‌ها -> diagrams/
python3 -m pytest tests -q          # تست‌ها
```

ساختِ گزارش از ریشه‌ی درختِ چندتمرینیه (جایی که پوشه‌های exercise-N کنارِ
هم‌اند):

```bash
python3 tools/build_report.py lst3_en exercise-3 REPORT_EN
python3 tools/build_report.py lst3_fa exercise-3 REPORT_FA
```
